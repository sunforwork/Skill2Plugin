# PDF work in Chat

Work from the PDF the user attaches, quoted pages, or a clear description. Identify the requested pages and output first. When the Chat environment provides a file or rendering tool, inspect relevant pages visually before commenting on layout and verify a generated PDF by rendering it. For text-only access, distinguish extracted text from visual evidence and ask for the specific page image if layout determines the answer.

Summarize or compare only content actually available. Preserve page citations when the source has page numbers. If creating a PDF, use available document tools and provide the generated file; otherwise provide the content or a reproducible template without claiming a file was made. Do not require a local terminal or package installation to answer a Chat request.
